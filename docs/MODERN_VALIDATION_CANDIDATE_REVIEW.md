# Modern Validation Candidate Review

The archived KBTV Snow Squall Warning search for 2019-2026 returned 87 warning products.

Those products cluster into 26 temporal warning episodes using a 30-minute continuity gap. The episode grouping is a review aid, not truth labeling.

## Episode review principles

A warning episode is only a candidate for independent reconstruction.

Before promoting an episode into the modern validation manifest, review:

- event-specific documentation or impact evidence;
- archived KCXX/KTYX Level-II availability;
- an evidence-bounded analysis window;
- surface observations from an appropriate station network;
- MRMS availability when within its defensible archive era;
- whether the episode is independent of the Banacos development population;
- whether adjacent warning episodes are actually the same storm evolution.

The automated discovery output intentionally sets every warning product to review-required and reconstruction-ineligible.

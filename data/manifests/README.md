# Dataset Manifests

These CSV manifests are the authoritative bookkeeping layer for the living dataset.

Large scientific files do not belong in normal Git history.

Each case should ultimately have:

- case manifest entry
- radar volume manifest
- environmental source manifest
- MRMS source manifest
- surface observation manifest
- label/evidence record
- processing/version metadata

A case is not considered training-ready until its provenance and label confidence are documented.
